# 2026-10-12 过月自动功能恢复

本次同时检查同道商人自动购买、元鸡喂养、促织存取和自动收获，保留并合并
2026-10-08 尚未提交的元鸡修复。实际游戏安装已更新到 Steam build `25845203`，
全部 API 查询和正式编译使用当前安装的程序集。

## 后端三项功能同时失效的原因

实际后端日志 `Logs/GameData_2026-10-08_23_15_50.log` 的 50–57 行记录：
`AdvanceMonthDiagnosticsCharacterPlanningAgentSelectActionTargetPatch` 找不到目标，
整个 `month` 组被回滚。前端 `Player.log` 的 `Installed patch group: month`
仅代表前端成功，不能证明后端安装成功。

原诊断补丁指定 `CharacterPlanningAgent.SelectActionTarget` 四参数重载；当前
原生方法新增第五个 `bool allowMovement`。修复补丁签名，并在通用
`AdvanceMonth` 分类之前分出独立组：

| 补丁类型前缀 | 安装组 |
| --- | --- |
| `AutoMonthlyPurchase` | `monthly-purchase` |
| `AutoCultivation` | `cultivation` |
| `AdvanceMonthDiagnostics` | `month-diagnostics` |
| 其余含 `AdvanceMonth` | `month` |

因此诊断或性能补丁失败时，不再取消采购和养殖功能；采购组故障也不会取消养殖。
保留此前同道商人遍历全部同道和隔离单店失败的修复，以及元鸡空来源回退、
实例编号 0、伏龙剧情空数据和实际好感度进展检查。

促织 `GetInventoryItems(..., 1100)`、存入/取回参数和原生过月回复顺序均未改变，
本次不改其游戏规则。该功能仍要求产业地块、蛰室空槽里已有罐、行囊促织存活且
耐久未满。自动取回会按原生规则返回行囊或仓库。低品罐需多月累计回复时，
每月取回会由原生清零回复计数；关闭自动取回可持续存放。

## 自动收获的独立问题

原生 `AdvanceMonth_DisplayedMonthlyNotifications(bool saveWorld)` 无论是否保存，
都会结束过月。原 Mod 却在 `saveWorld == false` 时不标记收获任务，导致跳过
自动保存的合法完成路径无法触发收获。现在只按功能开关决定是否收获。

另外，长保存或长过月超过 240 次轮询后保留待执行任务，停止轮询并等待已有
状态事件唤醒；合并待执行/执行中的重复标记，拒绝 Reset、重新加载世界前留下
的旧延时回调。保留领取物品、羽毛和招募处理的原有流程。

最新本地游戏日志只覆盖模块初始化至主菜单退出，没有载入世界或过月记录。
它确认了后端安装故障；自动收获的上述分支由当前 API 和离线测试复现确认，
不能由该日志确定用户实际遇到的是哪一个收获分支。
